# Folder ini untuk `google-services.json`

Letakkan file `google-services.json` dari Firebase console di folder ini
(namanya harus persis `google-services.json`).

Cara mendapatkannya:
1. Firebase console → ikon ⚙️ → **Project settings**
2. Tab **General** → bagian **Your apps** → **Add app** → ikon **Android**
3. Android package name: `com.erikoni.wedding`
4. Unduh **google-services.json** dan unggah ke folder ini.

Tanpa file ini APK tetap jadi, tetapi notifikasi push dari pasangan tidak masuk.
File ini berisi pengenal proyek, bukan kunci rahasia, jadi aman berada di repo.
